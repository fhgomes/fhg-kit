## What this is

fhg-kit — framework-free shared library for the fhgomes constellation of micro-SaaS products (LLM usage ledger and cost estimation first; credentials, flags, audit and integration contracts to follow)

- **Type:** Java shared library (Gradle multi-module, published to GitHub Packages)
- **Stack:** Java 21, Gradle 8.14.3 (Kotlin DSL), JUnit 6, AssertJ, jspecify, Spring Boot 4.1.2 (starter module only), GitHub Actions
- **Generated by:** projects-machine on 2026-10-25 (template conventions below are the
  house standard; update this file when the project drifts from them, do not let it rot).

## Conventions (Do-Not-Break)

1. **Versions are pinned.** Every dependency version lives in `gradle.properties`; every
   Docker image uses an exact tag plus digest. Never `latest`, never a floating tag such as
   `:pg18`. A floating tag does not break the build; it produces silent divergence between
   hosts (and, for a database, a one-way schema migration on boot).
2. **One version number.** `gradle.properties:appVersion` is the source of truth. A frontend
   `package.json` follows it; bump both together with `scripts/bump-version.sh <version>`.
3. **Migrations are append-only.** Flyway scripts under `db/migration` (or Liquibase changesets under `db/changelog`) are never edited after
   they ran anywhere. Hibernate runs with `ddl-auto: validate`; the schema is owned by the
   migrations, not by the entities.
4. **Containers run as the host user.** On Fernando's hosts everything runs as uid/gid
   `1001:1001` through `docker-compose.override.yml` (never `USER` in the Dockerfile). Bind
   mounts belong to that user. Copy `docker-compose.override.yml.example` on the host.
5. **Nothing listens on `0.0.0.0`.** Published ports bind `127.0.0.1` (and, on the host, the
   tailnet address via the override). A reverse proxy in front does TLS and subpaths.
6. **A new Docker network needs a firewall rule** for the host's LLM proxies (3457/3458),
   otherwise the symptom is "app UP, chat broken, HTTP 000, nothing in the app log". Derive
   the subnet with `docker network inspect`; never copy it from another host.
7. **Never build under `sudo`.** It leaves root-owned files in `~/.gradle` and `~/.npm`, and
   the next build as the normal user dies with `EACCES`.
8. **Backups are part of the product.** `BACKUP-RESTORE.md` says what is backed up, what is
   not, and how to restore. The compose stack ships a `backup` sidecar; keep it.
9. **Constructor injection, early returns, no magic numbers, 120 columns, 4 spaces.**
   `snake_case` columns, `AbstractEntity` base, UUID ids, `dh_`/`num_` column prefixes.
10. **Feature flags default OFF**, named `FHG_KIT_FEATURES_<NAME>_ENABLED`, read from
    the environment. Paid or risky features ship behind a flag.

## Constellation conventions (how this project connects to the others)

This repository is one star in a constellation of independent products that talk only
through contracts. Keep these surfaces stable and documented:

| Surface | Path / rule |
|---|---|
| Internal SPA API | `/api/v1/**` (JWT), `/api/public/**` (anonymous) |
| Integration API | `/api/integration/v1/**`, OpenAPI snapshot committed under `docs/integration/`, errors as RFC 7807 problem details with a stable `code`, `ETag`/`If-Match` on mutable resources, preview → confirm for side effects |
| MCP | `POST /mcp`; every MCP capability must also exist on the integration API (parity test) |
| Credentials for machines | prefixed API keys (`fhg-kit_…`), hashed at rest, with scopes and expiry; OAuth 2.1 for MCP clients |
| Outbound events | signed webhooks, idempotent by `event_id`, retried with backoff and a delivery log |
| AI usage | every LLM call records app, tenant, purpose, provider, model, tokens in/out, latency, estimated cost and `run_id`; budgets per purpose; the fake provider is forbidden in prod |
| Audit and consent | append-only `audit_log`; consent records; data export and erasure endpoints |

When the shared `fhg-kit` library ships a module for one of these rows, depend on it instead
of re-implementing the row here.
